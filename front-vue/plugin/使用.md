# Plugin 文件夹使用文档

## 概述

plugin 文件夹包含项目所有 Vite 插件的配置和封装，通过统一的入口函数`createVitePlugins`管理，实现插件的按需加载和模块化配置。

## 核心入口文件

### index.js

```javascript
import { createVitePlugins } from "./plugin/index.js";

// 在vite.config.js中使用
export default defineConfig(({ mode }) => {
  const viteEnv = loadEnv(mode, process.cwd());
  return {
    plugins: createVitePlugins(viteEnv, mode === "production"),
  };
});
```

## 插件列表及配置说明

### 1. 组件自动注册插件

**文件路径**：vitePlugin_autoRegistryComponents.js
**功能**：自动扫描并注册组件，无需手动 import
**主要特性**：

- 支持扫描`src/components`和页面级组件
- 自动解析 ElementPlus、VueUse 和图标组件
- 支持 TypeScript 类型声明生成

### 2. 自动导入插件

**文件路径**：unfinish/vitePluginAutoImport.js (开发中)
**功能**：自动导入 Vue、Pinia、VueRouter 等 API
**主要特性**：

- 支持 Vue3 组合式 API 自动导入
- 集成 ElementPlus 组件按需导入
- 自动生成 ESLint 配置

### 3. 压缩插件

**文件路径**：vitePlugin_compress.js
**功能**：静态资源压缩，支持多种压缩算法
**配置选项**：

```javascript
// 默认配置
ConfigCompressPlugin({
  isBuild: true, // 仅在生产环境启用
  deleteOrigin: false, // 是否删除原始文件
  algorithm: "gzip", // 压缩算法
  threshold: 10240, // 触发压缩的文件大小阈值(10KB)
});
```

### 4. HTML 处理插件

**文件路径**：vitePlugin_html.js
**功能**：HTML 模板注入、压缩和环境变量处理
**主要特性**：

- 动态注入标题、元数据
- 开发环境添加调试信息
- 生产环境支持 CDN 资源注入

### 5. 图片压缩插件

**文件路径**：vitePlugin_imageMin.js
**功能**：基于 `sharp + svgo` 优化图片资源，减小包体积
**支持格式**：jpg、png、svg、webp、avif
**质量配置**：

- jpg: 60 (0-100)
- png: 85 (也支持 `[min, max]` 形式，内部会自动取平均值)
- webp: 85
- avif: 80

### 6. 打包分析插件

**文件路径**：vitePlugin_inspectVisualizer.js
**功能**：生成打包体积分析报告
**使用方式**：

```javascript
createBundleVisualizer({
  enabled: true, // 启用插件
  openAnalyzer: true, // 自动打开报告
  reportFilename: "stats.html",
});
```

### 7. 构建进度条插件

**文件路径**：vitePlugin_progress.js
**功能**：显示构建进度，提升开发体验
**默认格式**：`构建中 |:bar| :percent | 耗时: :elapsed 秒`

### 8. 自动重启插件

**文件路径**：vitePlugin_restartVite.js
**功能**：监听配置文件变化自动重启 Vite
**默认监听文件**：

- 根目录配置文件(\*.config.[jt]s)
- Vite 配置文件(vite.config.[jt]s)
- 环境变量文件(.env\*)
- package.json

## 插件集成流程

1. 在 vite.config.js 中导入 createVitePlugins
2. 加载环境变量
3. 调用 createVitePlugins 并传入环境变量和构建状态
4. 根据需求在对应插件文件中调整配置

## 注意事项

- 生产环境构建时自动启用压缩和图片优化
- 开发环境禁用耗时的优化插件以提高构建速度
- 未完成插件请勿在生产环境使用
